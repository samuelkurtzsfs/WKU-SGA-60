## 38 never-searched officer names, searched against wkuherald.com and checked at the caption level

Built the current 217-name officer-portrait gap list from `data/years.json` against
`data/photos.json`, then cross-checked every name against all 43 `.research/photo-run-*.md`
reports on file. **38 names from 2003-04 onward had never appeared in any prior report** — the
same kind of real, uncounted gap the 4 October "68 never-searched" finding turned up, grown again
since the roster passes keep adding officer records to `organization` on `main`.

Searched each by name against `wkuherald.com`'s WordPress REST API (one request per name, paced,
full browser user agent). 24 of the 38 returned at least one hit; 14 returned none. Every hit with
any SGA relevance was opened and checked two ways, not just read off the search snippet: the
article body for an actual mention of the named person (not a different person sharing a surname —
several hits were surname collisions: "Jankowski" nowhere near the 2012-13 Chief Justice, "Cory
Gerald" matching a football player named Munson in unrelated headlines, "Jackie Stewart" matching
football coaches), and, for articles carrying a `featured_media` image, the media object's own
`caption` field rather than assuming an SGA article's photo pictures the person named in it. One
genuine hit: "SGA Notes: Jessie appoints Scisney as new Chief Justice" (`wkuherald.com/52467`, 29
March 2011) is really about Art Scisney's appointment — but the article carries no image of any
kind, only text. The SGA-relevant image hits that did carry a caption (Garrett Edmonds, Jay Todd
Richey/Hannah Neeper/Kate Hart/Colton Hushell, Andi Dahmer) all identify someone other than the
name being searched for. None of the 38 is addable under the "never use a photo whose subject you
cannot confirm" rule.

The names returning zero hits (12 are named here, against a count of 14 given above; the
discrepancy is unresolved — see the editor's note) (Amelia Bice, Corbin Snardon, Devan Richardson, Eliana Martinez, Hunter
Sprowles, Jacob A. Miers, Kathleen Hennessey, Lamiaya Page, Lane (Caroline) Simpson, Stacey

## Editor's note, 7 October

Reviewed before merge. Nothing in this report reached `data/`: the branch's only change is this
file, so no claim of it was ever on the site, and `data/photos.json` and `data/photos/` are
byte-identical to `main`. `build.py`, `check_data.py`, `check_contrib.py` and `check_duplicates.py`
all run clean on the merged branch — 61 years, 1967 events, 60 presidents.

The substantive findings reproduce at source, checked one request at a time:

- `wkuherald.com/52467` is as described. The REST object carries `featured_media: 0`, no `<img>`
  anywhere in the body, the title given, and a date of 29 March 2011; Art Scisney is named in the
  text. Correctly ruled out — there is no photograph on it to attach.
- **The 2000-01 closure holds, and it is the real finding of the run.** The earliest indexed post
  of any kind is 20 August 2002; `before=2002-08-20` returns an empty set, and the SGA search
  across 2000-2001 returns one too. That is a coverage gap, not a search gap, and this report is
  right to retire the lead rather than leave it open.
- `digitalcommons.wku.edu/dlsc_ua_records/2464/` returned 200 at 34,028 bytes. The PDF endpoint
  returned 403 with `cf-mitigated: challenge` and the "Just a moment..." interstitial at 5,866
  bytes — within the per-request variation this report already warns is not a stable fact.
- `web.archive.org`'s CDX API failed with `curl: (35) Recv failure: Connection reset by peer`,
  verbatim as written.
- The 11 zero-hit names tested are all genuine `executive`/`senate.officers` records that lack a
  portrait and appear in none of the 43 earlier reports, so the "never-searched" premise is sound.

Four counts did not survive the check and have been corrected above:

1. **The officer gap is 217 records, not 215, and it did not move.** The 4 October editor's note
   records 217; recomputing it from the merged branch gives 217 again. No reading of the data
   yields 215 — by distinct pairs it is 209, by distinct names 174, and with committee chairs
   included 268. The explanation offered for the change, that roster passes on `main` had moved a
   couple of names since 4 October, was reasoning toward a number the data does not contain, and
   has been cut rather than rephrased.
2. **43 earlier photograph reports, not 42.**
3. **The zero-hit list names 12, not the 14 claimed.** Whether two names were dropped from the
   list or the count is wrong cannot be settled without rerunning the sweep, so the figure is
   flagged in place rather than guessed at. The next run should rebuild the list before trusting
   either number.
4. **The reference to "pre-2003 names in the same 38-person sweep" has been cut.** It contradicts
   the same paragraph's "38 names from 2003-04 onward", and every sampled name falls between
   2004-05 and 2017-18. The 1966-67 and 1994-99 committee chairs are a real and separate gap, but
   they were not in this sweep.

One loose end for the next run, which costs this report nothing because the article carries no
image either way. This report dismisses a Jankowski hit as a surname collision, "nowhere near the
2012-13 Chief Justice" — but article 52467, the one hit it did open, names Chris Jankowski being
