## The actual finding this pass: a stale editorial-decision backlog

`data/photo-finds/_for-the-editor.md` holds a set of "face proved, person not proved" write-ups —
cases where a researcher found a specific, well-documented photograph and could not close the gap
between the face and the officeholder with full certainty. CLAUDE.md's rule against publishing an
unconfirmed identification means none of these should go up without someone making that call. The
file has existed since 8 September 2026 and asks explicitly for an editor's decision on each entry.

**Checked it against current `data/photos.json` and `data/photo-finds/_do-not-use.json` for the
first time this pass (no prior run's PR comments on #835 mention this file at all).** Five of the
original seventeen people are no longer open — three correctly rejected with real reasons and
moved to `_do-not-use.json` (David Young, Crystal Smith, Cody Cox — the last one is a genuine
privacy withdrawal, not an identification failure, see below), one correctly published
(George/Georgiana Carlson), and one partially closed (Sawyer Coffey's wkuherald.com lead is dead,
but a separate Talisman PRSSA-photo lead for her is still open). Cleaned the file to remove the
five resolved write-ups so a future run does not re-litigate them.

**Thirteen people, fourteen entries are still genuinely open and have had no decision in two and a
half months:** Debbie Thomas (1980-81), Nicki Jerome (1992-93), John Chestnut (1993-94), Grace
Hancock (1994-95), Amy Renigar (1995-96), Kristi Myers (1995-96), Lori Doolin (1995-96, two
candidate frames), Curtis Street (1996-97), Leigh Bakken (1996-97), Bill Brown (1998-99), Mark
Page (1998-99), Heather Francis (2002-03), Keanan Noel Cortney (2002-03), and the Sawyer Coffey
PRSSA photo (2016-17). Every one of these is a case where no further web or archive research can
move the needle — the face and the frame are already established in detail in the file itself;
what's missing is a source tying that specific face to the specific SGA officeholder, and nobody
has found one. This is a judgement call about how much circumstantial evidence is enough, which is
an editorial decision, not a research gap.

One entry, Cody Cox, deserves separate note: the face and the identification were both solid, but
it was correctly withdrawn because the only photograph of him is from a Herald feature about his
personal life unrelated to his SGA service, and publishing it as his SGA portrait would repurpose
a photograph he gave for one reason to a different one. That one is settled and should not be
reopened; it is noted here only because the stale version of `_for-the-editor.md` still described
it as "held for you to decide," which was no longer true and might have led a future run to
re-raise a question someone had already answered correctly.
