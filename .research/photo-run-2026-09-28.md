## New this run: web.archive.org is reachable again

Every recent report in this file had logged `web.archive.org` as closed (TLS reset at the
egress proxy). Retested it today and it answers, though not reliably — direct page fetches and
the CDX search API both succeed roughly one attempt in two or three, failing the rest with
`ws_closed_mid_exchange` at the proxy. Spacing requests out and retrying got through every time
eventually. This is a materially different state than the last two weeks of entries in this file
recorded, so future runs should retry it rather than assume it is still closed.

Used the restored access to pull the WKU SGA departmental website's own CDX history
(`wku.edu/Dept/Org/Student/SGA/*`) looking for a photo route around the still-blocked
`digitalcommons.wku.edu/cgi/viewcontent.cgi` (retested directly this run, still a Cloudflare 403
with full browser headers — unchanged). Found:

- `e_profiles.html` and `l_profiles.html` — the site's own executive and senate officer profile
  pages, captured several times between January 2004 and February 2005. Fetched the executive
  page as it stood 3 November 2004 (which names 2004-05 president Patti Johnson, administrative
  vice president Evelina V. Petkova and public relations director Abby Lovan — all three already
  on file in `data/years.json` under exactly those offices, so the page adds no name but does
  independently corroborate that year's recorded executive from a contemporaneous source) and
  the full senate profile page from the same date. **Neither page embeds
  a single `<img>` tag anywhere in its HTML**, despite a `Pics/ProfilePics/` directory existing
  on the same site and holding one image (`64aa.jpg`, 90KB, captured November 2004). The profile
  tables have an empty photo cell reserved (`<td valign="TOP" width="144">`) that the page's own
  authors never filled in. This is a source-side gap, not a crawl failure: the photos were never
  published to these pages in the first place, so no amount of retrying will find them here.
  `64aa.jpg` itself was not fetched or used — nothing on the crawled pages names who it shows, and
  a filename is not an identification.
- No other image paths under the SGA site's CDX history from any year land on anything but
  navigation icons, logos and legislation-cover PNGs (checked the full `mimetype:image.*` listing,
  30 files total across the site's entire crawl history).

## wkuherald.com checked against the priority-3 gap

`wkuherald.com`'s WordPress search reaches back to 2002 (confirmed against known early hits), so
tried it against fifteen of the 2010s officer names still missing a portrait: Brittany Crowley,
Jessi Wurth, Aaron Pawley, Sarah Howell, Smita Peter, Mark Clark, Liz Goddard, Jeremy Glass,
Samantha Hughey, Abhishek Bose, Sawyer Coffey, Zachary Skillman, Tribhuwan Singh, Rachel
Keightley, Ian Hamilton. Six (Howell, Goddard, Glass, Hughey, Singh, Skillman) return nothing.
The remaining nine return articles that quote the person but not one whose featured image is captioned
with their name — the pattern on this site is a generic meeting-room or unrelated-event photo
with a caption naming whoever the camera actually caught (checked each one: Sawyer Coffey's best
hit is captioned to a bystander at a class project event unrelated to SGA; Smita Peter's best hit
carries no caption on its image at all, so it would need identifying by matching a face without
a caption, which the archive's own rule forbids, and the subject matter of that article is in
any case not one this project should attach an officer portrait to). Nothing usable found. This confirms the featured-image
route on this site is a real but narrow one — captions do sometimes name a specific person — so
it is worth trying again per-name for anyone not yet attempted, but it did not pay off for the
fifteen names tried here.
