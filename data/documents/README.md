# Archive documents

PDFs downloaded from TopSCHOLAR live here, one file per document, named like
`1974-75-senate-minutes.pdf`. The build copies everything in this folder to
`site/docs/` so the site serves the actual file, not just a link.

Attach each file to its year in `data/years.json` under `documents`. The format
is in CLAUDE.md. Only mirror files that are openly downloadable from
TopSCHOLAR, and always keep the source link to the original.
